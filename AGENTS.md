### Contexto del proyecto

### Issue tracker

Los issues y specs viven en GitHub Issues de `BTG47/sms-android-app-with-rsa-security` y se opera con `gh`. Los tickets se implementan en ramas `bruno/feature/<nombre_de_rama>`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Se usan las cinco etiquetas canónicas: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` y `wontfix`. Ver `docs/agents/triage-labels.md`.

### Domain docs

Repositorio single-context: `GLOSSARY.md` y `docs/adr/` en la raíz. Ver `docs/agents/domain.md`.
